# 온톨로지 워크숍 실습 자료

비개발 실무자를 위한 지식 운영 실습 키트. 파이썬 표준 라이브러리만 사용합니다.

## 1주차 — RAG 체험

사내 근무 규정 문서 10장을 놓고, 검색 기반 AI(RAG)를 직접 만들어보며
"AI에게 무엇을 얼마나 주는가"가 비용과 정확도를 어떻게 바꾸는지 확인합니다.

```
week1/
  docs/       근무 규정 원본 10장
  split.py    문서를 조항 단위 '조각'으로 나눈다
  index.py    조각을 훑어 '색인' 한 장을 만든다
  ask.py      색인으로 조각을 찾아, 찾은 조각만 AI에게 넘긴다
```

AI를 부르는 단계에는 로그인된 `claude` CLI가 필요합니다.

---

### 1. 문서를 조각으로 나눈다

```bash
cd week1
python3 split.py
```
```
원본 10장  →  조각 103개   (chunks/ 에 저장했습니다)
```

`chunks/` 폴더에서 조각 하나를 열어봅니다. 조항 하나가 조각 하나입니다.

### 2. 조각을 훑어 색인을 만든다

질문하기 전에 딱 한 번 실행합니다.

```bash
python3 index.py
```
```
조각 103개  →  색인 1장 (index.tsv, 13,464바이트)
```

`index.tsv`를 메모장으로 열면 어떤 조각에 어떤 말이 들어 있는지 한눈에 보입니다.

### 3. Claude Code에서 직접 물어본다

검색 코드 없이, 평소처럼 물어봅니다.

```bash
cd docs
claude
```

Claude Code가 뜨면 그대로 입력합니다.

```
docs 폴더의 문서만 읽고 답해줘. 폴더 밖의 스크립트는 찾지도 실행하지도 마.
연장근로 규칙 알려줘
```

> 스크립트를 막는 문장이 꼭 필요합니다. 그냥 물어보면 Claude Code가
> 상위 폴더에서 `ask.py`를 찾아 대신 실행해버려서, 4번과 같은 것을 하게 됩니다.

답이 나오면 이어서 `/context`를 입력합니다.

**볼 것 두 가지**
- 답이 나오기까지 **파일을 검색하고 여는 과정이 화면에 몇 번 뜨는지** 세어봅니다.
- `/context`의 **Tokens** 값. 질문 전에도 한 번 실행해두면 얼마나 늘었는지 알 수 있습니다.

확인이 끝나면 `/exit` 후 `cd ..` 로 돌아옵니다.

### 4. 색인으로 찾아서 조각만 넘긴다

```bash
python3 ask.py "연장근로 규칙 알려줘"
```
```
  검색어      : ['연장근로']
     3점  03-연장근로-05.md  제5조 (연장근로의 한도)
     2점  04-임금및수당-05.md  제5조 (연장근로수당)
     2점  03-연장근로-10.md  별표 1 (연장근로 가산율)
  열어본 파일 : 4개  (index.tsv 1 + 조각 3)
  넘긴 글자   : 518자
  ── AI 호출 ──
  대화 턴     : 1회
  ...
```

`--검색만`을 붙이면 AI를 부르지 않고 검색 결과만 봅니다.

### 5. 규정에 없는 말로 물어본다

```bash
python3 ask.py "야근 규칙 알려줘"
```
```
  검색어      : ['야근']
  찾은 조각   : 0개  ← 색인에 이 단어가 없습니다
  넘긴 글자   : 0자

[답변] 관련 내용을 찾지 못했습니다.
```

규정은 전부 '연장근로'라고 씁니다. 현업이 부르는 이름과 규정에 적힌 이름이 다르면
글자가 겹치지 않아 한 건도 찾지 못합니다.

### 6. 답이 나오지만 반쪽인 경우

```bash
python3 ask.py "통상임금 시급이 2만원인데 어제 2시간 더 일했어요. 수당 얼마 받아요?"
```
```
     4점  04-임금및수당-03.md  제3조 (통상임금)
     3점  04-임금및수당-06.md  제6조 (야간근로수당)
     3점  04-임금및수당-05.md  제5조 (연장근로수당)
  넘긴 글자   : 560자
```

AI는 이렇게 답합니다.

> 연장근로 가산율은 「연장근로 및 휴일근로 운영규정」 **별표 1**에서 정한다고만 되어 있고,
> 그 별표 1의 구체적 가산율(%)은 이 근거에 포함되어 있지 않습니다.
> … **별표 1 없이는 계산이 안 됩니다.**

검색은 `수당`이라는 글자로 04번 문서를 찾아줬습니다. 그런데 그 문서는
**다른 문서를 가리키고 있고, 검색은 그 화살표를 따라가지 않습니다.**

### 7. 화살표를 직접 따라가 본다

`docs/03-연장근로.md`의 **별표 1**을 직접 열어봅니다.

```
1. 사전 승인을 받은 연장근로: 시간당 통상임금의 150퍼센트
2. 사전 승인을 받지 아니한 연장근로: 근로시간으로 인정하지 아니하므로 지급하지 아니한다
```

- 사전 승인을 받았다면 20,000 × 1.5 × 2 = **60,000원**
- 승인을 받지 않았다면 **0원**

**던질 질문: 이 답을 믿고 6만원을 청구할 수 있었을까요?**

---

### 3번과 4번의 차이

같은 질문(`연장근로 규칙 알려줘`)을 두 방식으로 처리한 실측값입니다.

| | 3. 직접 물어보기 | 4. 색인으로 찾기 |
|---|---|---|
| 대화 턴 | 3 ~ 5회 | **항상 1회** |
| 읽은 토큰 | 146,644 ~ 153,909 | **33,155 ~ 46,048** |
| 걸린 시간 | 30.8 ~ 40.0초 | **10.7 ~ 21.1초** |

토큰과 시간은 실행할 때마다 흔들리지만 **대화 턴 수는 흔들리지 않습니다.**
색인이 있으면 AI가 헤맬 일이 없어서 한 번에 끝납니다.

> 읽은 토큰에는 어느 방식이든 깔리는 기본값이 포함되어 있습니다.
> 4번에서 실제 근거로 넘긴 것은 518자뿐입니다.

### 두 종류의 실패

| | 5번 (야근) | 6번 (수당) |
|---|---|---|
| 결과 | 답을 못 함 | **답을 함** |
| 원인 | 글자가 안 겹침 — **이름이 다르다** | 화살표를 안 따라감 — **관계를 모른다** |
| 위험 | 낮다. 못 찾은 걸 안다 | **높다. 반쪽인 걸 모른다** |

### 이 실습에서 확인하는 것

- RAG는 **문서를 조각내고 → 색인을 만들고 → 질문에 맞는 조각을 찾아 → 그 조각만 AI에게 주는 것**이다.
- 색인이 있으면 AI가 헤매지 않는다. 대화 턴이 여러 번에서 한 번으로 줄어든다.
- 그래도 **이름이 다르면 못 찾고, 관계가 적혀 있지 않으면 못 따라간다.**
  더 똑똑한 도구를 붙이는 것으로는 해결되지 않는다.
