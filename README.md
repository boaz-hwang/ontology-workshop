# 온톨로지 워크숍 실습 자료

비개발 실무자를 위한 지식 운영 실습 키트. 파이썬 표준 라이브러리만 사용합니다.

## 1주차 — RAG 체험

사내 근무 규정 문서 10장을 놓고, 검색 기반 AI(RAG)를 직접 만들어보며
"AI에게 무엇을 얼마나 주는가"가 비용과 정확도를 어떻게 바꾸는지 확인합니다.

```
week1/
  docs/       근무 규정 원본 10장 (14,882자)
  split.py    문서를 조항 단위 '조각'으로 나눈다
  index.py    조각을 훑어 '색인' 한 장을 만든다
  ask.py      색인으로 조각을 찾아, 찾은 조각만 AI에게 넘긴다
```

---

### 1. 문서를 조각으로 나눈다

```bash
cd week1
python3 split.py
```
```
원본 10장  →  조각 102개   (chunks/ 에 저장했습니다)
```

`chunks/` 폴더를 열어 조각 하나를 확인합니다. 조항 하나가 조각 하나입니다.

### 2. 조각을 훑어 색인을 만든다

질문하기 전에 딱 한 번 실행합니다.

```bash
python3 index.py
```
```
조각 102개  →  색인 1장 (index.tsv, 13,343바이트)
```

`index.tsv`를 메모장으로 열면 어떤 조각에 어떤 말이 들어 있는지 한눈에 보입니다.

### 3. Claude Code에서 직접 물어본다

먼저 검색 코드 없이, 평소처럼 물어봅니다.

```bash
cd docs
claude
```

Claude Code가 뜨면 그대로 입력합니다.

```
연장근로 규칙 알려줘
```

답이 나오면 이어서 입력합니다.

```
/context
```

**볼 것 두 가지**
- 답이 나오기까지 **파일을 검색하고 여는 과정이 화면에 몇 번 뜨는지** 세어봅니다.
- `/context`의 **Tokens** 값을 적어둡니다. 질문 전에도 한 번 실행해두면 이번 질문으로 얼마나 늘었는지 알 수 있습니다.

확인이 끝나면 `/exit`으로 나와 `cd ..` 로 돌아옵니다.

### 4. 색인으로 찾아서 조각만 넘긴다

```bash
python3 ask.py "연장근로 규칙 알려줘"
```
```
  검색어      : ['연장근로']
     3점  03-연장근로-05.md  제5조 (연장근로의 한도)
     2점  04-임금및수당-05.md  제5조 (연장근로수당)
     1점  06-재택근무-07.md  제7조 (재택근무 중의 연장근로)
  열어본 파일 : 4개  (index.tsv 1 + 조각 3)
  넘긴 글자   : 524자
  ── AI 호출 ──
  대화 턴     : 1회
  읽은 토큰   : 33,155
  걸린 시간   : 17.9초
```

`--검색만`을 붙이면 AI를 부르지 않고 검색 결과만 봅니다.

### 5. 규정에 없는 말로 물어본다

```bash
python3 ask.py "야근 규칙 알려줘"
```
```
  검색어      : ['야근']
  찾은 조각   : 0개  ← 색인에 이 단어가 없습니다
  넘긴 글자   : 0자

[답변] 관련 내용을 찾지 못했습니다.
```

---

### 3번과 4번의 차이

같은 질문을 두 방식으로 처리한 실측값입니다. 각 2회 측정했습니다.

| | 3. 직접 물어보기 | 4. 색인으로 찾기 |
|---|---|---|
| 대화 턴 | 5회 | **1회** |
| 읽은 토큰 | 151,761 ~ 153,909 | **33,155 ~ 33,365** |
| 걸린 시간 | 30.8 ~ 34.6초 | **17.9 ~ 21.1초** |

실행할 때마다 조금씩 달라지지만 대화 턴 수는 5회와 1회로 일정합니다.

> 읽은 토큰에는 어느 방식이든 깔리는 기본값이 포함되어 있습니다.
> 4번에서 실제 근거로 넘긴 것은 524자뿐입니다.

### 이 실습에서 확인하는 것

- RAG는 **문서를 조각내고 → 색인을 만들고 → 질문에 맞는 조각을 찾아 → 그 조각만 AI에게 주는 것**이다.
- 미리 색인을 만들어두면 AI가 헤매지 않는다. 대화 턴이 5회에서 1회로 줄어든다.
- 대신 **검색이 놓치면 답이 없다.** 규정은 '연장근로'라고 쓰는데 현업은 '야근'이라 부르면,
  글자가 겹치지 않아 한 건도 찾지 못한다. 글자가 아니라 의미로 찾아야 한다.
