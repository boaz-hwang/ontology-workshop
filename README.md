# 온톨로지 워크숍 실습 자료

비개발 실무자를 위한 지식 운영 실습 키트. 파이썬 표준 라이브러리만 사용합니다.

## 1주차 — RAG 체험

사내 근무 규정 문서 10장을 놓고, 검색 기반 AI(RAG)가 실제로 어떻게 동작하는지
직접 만들어보며 확인합니다.

```
week1/
  docs/       근무 규정 원본 10장
  split.py    문서를 조항 단위 '조각'으로 나눈다
  index.py    조각을 훑어 '색인' 한 장을 만든다
  ask.py      색인으로 조각을 찾아, 찾은 조각만 AI에게 넘긴다
```

### 실행 순서

```bash
cd week1

# 1. 문서를 조각으로 나눈다
python3 split.py
#   → 원본 10장 → 조각 102개

# 2. 조각을 훑어 색인을 만든다 (질문하기 전에 딱 한 번)
python3 index.py
#   → 조각 102개 → 색인 1장 (index.tsv)

# 3. 문서를 통째로 넘길 때
python3 ask.py --전체 "연장근로 규칙 알려줘"
#   → 열어본 파일 10개 · AI에게 넘긴 글자 14,900자

# 4. 색인으로 찾아 넘길 때
python3 ask.py "연장근로 규칙 알려줘"
#   → 열어본 파일 4개 · AI에게 넘긴 글자 524자

# 5. 규정에 없는 말로 물어볼 때
python3 ask.py "야근 규칙 알려줘"
#   → 찾은 조각 0개 · 못 찾음
```

`--답변`을 붙이면 찾은 조각으로 실제 답변까지 생성합니다.
이 경우 로그인된 `claude` CLI가 필요합니다.

```bash
python3 ask.py --답변 "연장근로 규칙 알려줘"
```

### 이 실습에서 확인하는 것

- RAG는 **문서를 조각내고 → 색인을 만들고 → 질문에 맞는 조각을 찾아 → 그 조각만 AI에게 주는 것**이다.
- 조각만 넘기면 AI에게 가는 양이 크게 줄어든다. (14,900자 → 524자)
- 대신 **검색이 놓치면 답이 없다.** 규정은 '연장근로'라고 쓰는데 현업은 '야근'이라 부르면,
  글자가 겹치지 않아 한 건도 찾지 못한다.
